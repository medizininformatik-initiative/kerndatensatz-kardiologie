## Fragebögen und standardisierte Erhebungen

* **NYHA (New York Heart Association Functional Classification):** Klassifikation der Herzinsuffizienz
* **mRS (modified Rankin Scale):** Einschätzung des functional status nach Schlaganfall
* **ACRIBiS FollowUp Questionnaire:** Standardisiertes FollowUp in der ACRIBiS-Studie

## Glossar

| Begriff | Definition |
|---|---|
| **DIZ (Datenintegrationszentrum)** | Zentrale Einrichtung zur Aufbereitung und Strukturierung von Patientendaten im Kontext der MII |
| **KDS (Kerndatensatz)** | Standardisierte Sammlung von essentialen Datenelementen zur Forschung und Versorgung |
| **LVEF (Linksventrikuläre Ejektionsfraktion)** | Maß für die Pumpleistung des linken Ventrikels (normal >55%) |
| **NYHA (New York Heart Association)** | Klassifikation der Herzinsuffizienz-Schwere (Klasse I-IV) |
| **mRS (modified Rankin Scale)** | Skala zur Einschätzung des functional status nach Schlaganfall (0-6) |
| **ICD (Implantable Cardioverter-Defibrillator)** | Implantierbarer Defibrillator zur Primär- und Sekundärprävention plötzlichen Herztodes |
| **CRT (Cardiac Resynchronization Therapy)** | Resynchronisationstherapie bei Herzschwäche |
| **LVAD (Left Ventricular Assist Device)** | Linksventrikuläres Unterstützungssystem |
| **BiVAD (Biventricular Assist Device)** | Biventrikuläres Unterstützungssystem |
